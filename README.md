- [Dashboard de ventas](https://github.com/psoto212/dashboard-streamlit-ventas): base de aplicación Streamlit.

## Cómo utilizar este repositorio

Cada carpeta es independiente. Consulta sus fuentes y README antes de instalar dependencias o ejecutar ejercicios. Se conserva la estructura interna de las prácticas para respetar imports y referencias relativas. Los cuadernos se publican sin salidas guardadas y los conjuntos de datos no se incluyen.

Es una colección académica: puede incluir ejemplos parciales, ejercicios de examen, soluciones y borradores. No existe un comando único para ejecutarla completa. [La comprobación de sintaxis](docs/validacion.md) identifica limitaciones conocidas sin presentar los ejercicios como aplicaciones terminadas.

## Autoría y procedencia

El material reúne trabajo propio, trabajos en equipo y ejemplos o plantillas docentes. Se conservan las atribuciones de cada archivo. La publicación no declara autoría exclusiva ni añade una licencia sobre material de terceros. [El mapa de procedencia](docs/procedencia.csv) permite relacionar cada archivo de los paquetes anteriores con su nueva ubicación.

## Organización

Los ZIP originales permanecen en el archivo privado de respaldo. Este repositorio contiene los archivos navegables. Los 19 candidatos vacíos o auxiliares de macOS no forman parte de esta colección.

Se han excluido de esta edición pública 10 ejercicios con errores de sintaxis; consulta el informe de validación.

## Selección actual

La colección se ha ajustado a la selección del autor. Geometría y Ecuaciones Diferenciales se han retirado; Adquisición conserva las prácticas 2 y 3, Métodos Numéricos las prácticas y Sistemas las prácticas de laboratorio. Programación reúne la antigua carpeta Programación II y el proyecto en `proyecto/`. Los documentos de procedencia y validación anteriores son registros históricos; [el mapa de esta reorganización](docs/organizacion-actual.csv) identifica los archivos retirados y sus nuevas rutas. Las retiradas afectan a la versión actual, no al historial Git.
